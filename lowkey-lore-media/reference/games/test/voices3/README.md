# Voice 12 (Chatterbox, British prompt), natural pacing
Each phrase is generated on its own and assembled with real gaps, like normal speech:
- about 0.35-0.5 s between phrases
- 0.7-0.9 s before a punchline and after a big number, so it lands
- delivery slowed 5% with no pitch change
- the emotion dial is raised only on the big moments
- 12b-natural-short: the same line as before, 119 words/min (normal conversation is about 120-150)
- 12c-relaxed-short: slower, 97 words/min, for comparison
- 12b-natural-long-winner: a 25 s call of the Clasico winner ("Eighty-seven minutes... Camavinga skips past Cubarsi... Mbappe! Empty net.") over the crowd, which erupts on the goal
