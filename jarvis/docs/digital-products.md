# Digital products

Alfred helps you plan, make and manage digital products you sell yourself: printable planners, checklists, worksheets, ebooks, prompt packs, templates and wallpaper packs. He makes simple files, writes draft listing text and keeps track of your catalogue. He never uploads, lists, sells or posts anything, and he does not work out marketplace fees or income tax (other abilities cover those). Your data lives in `digitalproducts.json` in the memory folder, and the files he makes are in `digitalproducts/files`.

Please be realistic: nobody can promise a product will sell. Alfred's pricing help is arithmetic on your own numbers plus a reminder to check what similar products sell for. His licence and refund text is a plain-words draft, not legal advice; for UK consumer rights see GOV.UK.

There are four tools, found by tool search: `digitalproducts_catalogue`, `digitalproducts_make`, `digitalproducts_copy` and `digitalproducts_launch`. Prices are in pounds.

## Ideas, catalogue and versions (digitalproducts_catalogue)

| Say | What happens |
|---|---|
| "Save a product idea: a meal planner for students" | Saves it with a number |
| "Show my product ideas" | List; tap one to validate it |
| "Change idea 2 to a weekly meal planner" | Edits it |
| "Delete idea 2" | Asks first, then removes it |
| "Give me product ideas about gardening" | Ten starting points; tap to save one |
| "Validate idea 1" | Eight-question checklist pops up with ticks |
| "Tick items 1 and 3 for idea 1" | Updates the ticks and gives an honest verdict |
| "Rank my ideas" | Table with the most-checked ideas first |
| "Plan the meal planner as a printable planner at 4 pounds" | Turns an idea (or a new name) into a product and shows what it needs and which Alfred tool can make it |
| "Show the product Weekly Reset Planner" | Product details table |
| "Show my product catalogue" | Board of idea, making, listed and retired; tap a product |
| "Mark Weekly Reset Planner as listed" | Changes its status (you list it yourself) |
| "Change the price of Weekly Reset Planner to 5 pounds" | Edits price, audience, benefits or keywords |
| "Remove Weekly Reset Planner from my catalogue" | Asks first; its files stay |
| "Export my catalogue" | CSV file card |
| "How many products do I have?" | Bar chart of products by status |
| "Log a change to Weekly Reset Planner: added A5 pages" | Adds to the version log |
| "Show the update log" | Table of versions and changes |

## Making products (digitalproducts_make)

Printables come out as an HTML page ready to print (Ctrl+P, Save as PDF). Say "and a PDF too" to also save a simple PDF made by Alfred; it is plainer than the HTML. Add "for product X" to attach the file to that catalogue product.

| Say | What happens |
|---|---|
| "Make a weekly planner" (or daily, monthly for February) | Printable planner file card |
| "Make a moving day checklist: boxes, keys, meter reading" | Checklist page with tick boxes |
| "Make a worksheet called Goal Setting" | Worksheet with writing lines |
| "Make a habit tracker for March: read, walk, water" | Month grid of habits by day |
| "Make a printable budget sheet" | Table of planned, actual and difference |
| "Make an ebook skeleton called Calm Mornings with 8 chapters" | Markdown outline with chapter prompts |
| "Make a content calendar spreadsheet template" | CSV that opens in Excel or Sheets |
| "Make a prompt pack about baking, 20 prompts" | Markdown pack of starter prompts to test and reword |
| "Make a course outline of 5 lessons" | Markdown outline with goals and exercises |
| "Make 4 sunset phone wallpapers called Dusk" | Picture files (mono, sunset, ocean, forest, lavender, sand) |
| "Make a cover picture for Calm Mornings" | A simple PNG cover |
| "Show my digital product files" | List of files; tap to open |
| "Show the file moving-day" | File card |
| "Make a PDF of moving-day" | PDF from the page or Markdown file |
| "Delete the file moving-day" | Asks first |

## Listing copy, licences and customers (digitalproducts_copy)

| Say | What happens |
|---|---|
| "Draft a listing for Weekly Reset Planner" | Titles, description, benefits, FAQ and tags pop up and are saved |
| "Give me title options for it" | List of titles |
| "Show the listing" | The saved draft |
| "Check the listing" | Warns about risky claims (guaranteed, make money...) and gaps |
| "Save the listing as a file" | Markdown file to copy from |
| "Give me tag ideas" | List of keyword phrases |
| "Cover text ideas for it" | Seven ideas, with a button to make a cover |
| "Draft a FAQ for it" | Five common buyer questions |
| "Explain a personal use licence" | Plain-words licence (personal, commercial or teacher) |
| "Save a commercial licence file" | Markdown file to put in your download |
| "Save a customer answer: Can I print it twice? Yes, for yourself" | Adds to your customer FAQ |
| "Show my customer FAQ" | List |
| "What's my answer about printing?" | Finds the best match |
| "Delete customer question 3" | Asks first |
| "Draft a reply to: can I print this again?" | Reply text using your FAQ, for you to send yourself |
| "Draft an update note for Weekly Reset Planner" | Message for buyers from the latest logged change |
| "Draft a thank-you note" | Short buyer thank-you, no pressure for reviews |

| "Show my bundles" | Table |

## Left out on purpose

Uploading or selling, marketplace fee calculators, income and tax tracking, and the side hustle tools (hourly rate, break-even, order log) belong to other abilities.
