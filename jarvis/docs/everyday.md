# Everyday lists, habits and money

Things to say to Alfred:

- **To-do list**: "Add call the bank to my to-do list." / "Tick off the bank." / "What's on my to-do list?"
  It's `Personal/to-do.md` in the memory folders, or your own `JARVIS_TASKS_FILE` if you set one.
- **Habits**: "I went to the gym." / "I read yesterday." / "How are my streaks?" / "Stop tracking water."
- **Payslips**: "Read my payslips in the Work folder and log them." / "Log my September payslip from VGC, take-home 2,300."
- **Spending**: "I spent 12 pounds on lunch." / "Remove the last one." / "How much have I spent this month?"
- **Money summary**: "How's my money looking?" (recent payslips, average take-home, spending by category)
- **Currency**: "What's 50 pounds in rand?"
- **Search your notes**: "What did I save about the boiler?"

Set `JARVIS_CURRENCY` in `.env` if you don't use pounds (for example `JARVIS_CURRENCY=ZAR`).
