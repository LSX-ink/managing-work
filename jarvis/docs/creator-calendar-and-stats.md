# Creator calendar and stats

Alfred can plan your posting, keep the numbers you read off the app, and turn them into charts and reports. Everything is typed or spoken by you and stored in `creatorstats.json` in the memory folder. Nothing is fetched from TikTok or anywhere else, and Alfred never posts for you. Best-time and earnings advice is general guidance only, not a promise: your own numbers beat it. For tax on any income, check GOV.UK.

There are four tools, found by tool search: `creator_accounts`, `creator_calendar`, `creator_stats` and `creator_reports`.

## Accounts and goals (creator_accounts)

| Say | What happens |
|---|---|
| "Add account lowkey.lore on TikTok, niche scary stories" | Adds the account |
| "Change lowkey.lore's niche to true crime" | Updates platform, niche, goal or name |
| "Remove the account mindglitch.fyi" | Asks you first, then deletes with its videos |
| "Show my accounts" | Table of accounts with followers and goals |
| "lowkey.lore has 850 followers" | Logs today's follower count |
| "Set a goal of 10,000 followers by New Year" | Saves the goal |
| "How is my follower goal going?" | Goal table: need per day against your pace |
| "When will I hit 1k, 10k, 100k?" | Milestone table from your recent growth |
| "Post at 7:30, 12:30 and 19:30" | Saves up to three daily posting slots |
| "Show my posting schedule" | Weekly slots table |
| "When is the best time to post?" | General UK best-time windows table |
| "My weekday windows are 6 to 8pm" | Edits those windows (or resets them) |
| "Add 10k followers to my creator fund checklist" | Adds a checklist item (your own note) |
| "Tick off 10k followers" | Ticks or unticks an item |
| "Remove that checklist item" | Deletes it |
| "Show my eligibility checklist" | Checklist pop-up |

## Content calendar (creator_calendar)

| Say | What happens |
|---|---|
| "Plan 'Ghost story' for Friday at 7:30pm, theme creepy" | Plans a video (slots can't clash) |
| "Move Ghost story to Saturday" | Edits day, time, title, theme, hook or length |
| "Delete Ghost story from the plan" | Asks first, then removes it |
| "Show my content calendar" | Month grid pop-up; tap a day to hear what is planned |
| "What's planned on Friday?" | Day list |
| "What's coming up this week?" | Upcoming list |
| "Which posting slots are free?" | Empty slots table |
| "I posted Ghost story" | Marks it as posted (or logs a new title) |
| "What's my posting streak?" | Current and longest run of days |
| "How often am I posting?" | Bar chart of videos per week |

## Logging numbers (creator_stats)

| Say | What happens |
|---|---|
| "Ghost story got 5,000 views and 400 likes after 24 hours" | Logs stats at 1h, 24h or 7d |
| "How did Ghost story do?" | Scorecard table |
| "List my videos" | Table of videos |
| "What's my engagement rate on 1000 views, 100 likes?" | Rates table |
| "Which are my best videos by shares?" | Ranked table |
| "Which are my worst videos?" | Ranked table |
| "Show the views curve for Ghost story" | Line chart 1h to 7d |
| "Test two hooks: 'Nobody knew' against 'Last night'" | Starts an A/B test |
| "Hook A got 100 views" | Saves a hook's result |
| "Which hook won?" | Works out the winner (with a small-sample warning) |
| "Show my hook tests" | Table of tests |

## Reports and comparisons (creator_reports)

| Say | What happens |
|---|---|
| "Creator dashboard" | Accounts overview table |
| "Show my follower growth" | Follower line chart |
| "Are my views going up?" | Bar chart of views per video |
| "Weekly creator report" | This week against last week |
| "Monthly report for September" | This month against the one before |
| "What are my averages?" | Average, median and best views, engagement |
| "Compare my accounts" | Accounts side by side |
| "Compare Ghost story with Heist" | Two videos side by side |
| "Which day is best for me?" | Bar chart of average views per weekday |
| "Which hour is best for me?" | Table by posting hour |
| "Which themes work?" | Table by theme |
| "Do longer videos do better?" | Table by length band |
| "How many followers do I gain per 1,000 views?" | Conversion table |
| "Am I sticking to my plan?" | Planned against posted |
| "Roughly what would 10,000 views earn at 50p per 1,000?" | Estimate from your own rate, never a guess |
| "Export my stats" | Saves a CSV in the memory folder |
