# Repurposing content

Alfred can turn one video script or idea into many versions, and keep track of where each version has gone. It works on text and files only: it never makes videos, pictures or voices, and it never posts anywhere. Where you see "Alfred writes it", Alfred is given a short brief and writes the rewrite for you. Your plans and tracker live in `repurpose.json` in the memory folder, and subtitle files are saved in `repurpose/subtitles`. Timings come from your speaking pace (150 words a minute unless you say otherwise), so treat them as a starting point and nudge them to match your real recording. Character limits and best lengths are general guidance and the apps change them.

There are four tools, found by tool search: `repurpose_subtitles`, `repurpose_formats`, `repurpose_plan` and `repurpose_tracker`. It builds on the creator tools (ideas, scripts, calendar, stats) and doesn't repeat them.

## Subtitles, on-screen text, chapters (repurpose_subtitles)

| Say | What happens |
|---|---|
| "Make an SRT for this script called sleep tips" | Saves a timed .srt file; a file card pops up |
| "Make a VTT, three words at a time" | Saves a .vtt with punchy short captions |
| "List my subtitle files" | List of saved subtitle files |
| "Show the sleep tips subtitles" | Timeline pop-up of every subtitle |
| "Shift the sleep tips subtitles 2 seconds later" | Moves every timing |
| "Check the sleep tips subtitles" | Table of subtitles that are too fast, too long or overlap |
| "Give me the plain text of the sleep tips subtitles" | Transcript with timings stripped |
| "On-screen text for each beat of this script" | Timeline of short capitalised lines with times |
| "Check these YouTube chapters: 0:00 Intro, 0:45 Tips, 2:10 End" | Tidy chapter list, plus fixes if YouTube would reject it |
| "Suggest chapters from this script" | Chapter times worked out from word counts |
| "Build the description for Sleep better" | Saves a description with summary, chapters, links and up to 3 hashtags |

## Other versions (repurpose_formats)

| Say | What happens |
|---|---|
| "Split this script into 3 parts with cliffhangers" | Table of parts with word counts, speaking time and a cliffhanger line |
| "Show the Sleep series" / "Show part 2" | List of saved parts, or one part with a recap line |
| "Turn this into a YouTube Short" | Alfred writes it, about 110 words |
| "Rewrite it as an Instagram Reel" | Alfred writes it, with caption |
| "Make a Pinterest pin from it" | Pin title, description and image text |
| "Turn it into an X thread" | Text pop-up of posts, each under 280 characters and numbered |
| "Make it a blog post" | Alfred writes about 500 words with headings |
| "Write a newsletter paragraph" | Alfred writes a paragraph with a subject line |
| "Podcast talking points from this" | Alfred writes bullets, not a script |
| "Give me title ideas for sleep" | Table of 8 titles with lengths |
| "Check this title: 5 sleep mistakes" | Length, power words and number check |
| "Thumbnail text for this hook" | Table of cover-text options of four words or fewer |
| "Is STOP SNOOZING OK as cover text?" | Word and character check |
| "Pick quote cards from this script" | List of the strongest lines; tap one to shorten it |
| "What are the character limits?" | Table of limits per platform |
| "Does this fit an X post?" | Characters against the limit |
| "Calls to action for Pinterest" | Table of suggestions per platform |
| "What does each format want?" | Table of shapes, lengths and tips |

## Plans and checklists (repurpose_plan)

| Say | What happens |
|---|---|
| "Atomise the idea sleep into ten shorts" | List of up to 14 short-video angles; tap one for a script |
| "Show my atoms for sleep" | The list with what is made |
| "Piece 3 of sleep is made" | Ticks it off |
| "Delete the sleep atoms" | Asks first |
| "Start a repurposing checklist for Sleep video" | Checklist pop-up |
| "Tick subtitles on the Sleep video checklist" | Ticks or unticks a step |
| "Show my repurposing checklists" | List of videos and progress |
| "Remove the Sleep video checklist" | Asks first |
| "Show my checklist template" | Your default steps |
| "Change my checklist steps to cut, subtitle, post" | Saves your own steps (empty list resets) |
| "What can I make from a long video?" | Table of reuse ideas with effort |
| "Spread Sleep over a week from Thursday" | Table of which platform on which day; can save them to the tracker as planned |

## Tracker and evergreen reminders (repurpose_tracker)

You type in what you posted; Alfred never checks the apps.

| Say | What happens |
|---|---|
| "Log Sleep on TikTok, posted yesterday" | Records a version (planned, draft, scheduled or posted) |
| "Mark version 4 as posted" | Edits status, date, link or note |
| "Remove version 4" | Asks first |
| "Show the versions of Sleep" | Table with numbers, dates and links |
| "Show my cross-platform tracker" | Grid of videos by platform; tap a cell |
| "Where is Sleep missing?" | Posted, planned and missing platforms |
| "I post on TikTok, Shorts and Blog" | Sets your platform list |
| "How many versions have I posted?" | Bar chart per platform |
| "Export my tracker" | CSV file in the repurpose folder |
| "Sleep is evergreen, re-post every 6 months" | Saves the reminder |
| "What is due for a re-post?" | List of overdue and due-soon videos; tap one once done |
| "Show my evergreen videos" | Table of re-post dates |
| "I re-posted Sleep today" | Restarts its clock |
| "Stop the Sleep evergreen reminder" | Asks first |
