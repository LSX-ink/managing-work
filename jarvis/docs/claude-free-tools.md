# Claude's free tools in Alfred

Everything Claude can do for free, Alfred can now do too. Say "Show me Claude's free tools" (or open the
**BOTS** window and tap **Claude's free tools**) to see the list on the screen.

## New
- **Free web search, on every brain**: "Search the web for ..." Claude's own web search only works when Claude
  answers. When the free AI answers, Alfred now searches DuckDuckGo himself (Wikipedia if that's busy), so he
  always has the web. No account, no key, nothing to pay.
- **Read any web page or online PDF**: "Read this page: https://..." or "What does page 3 of this PDF say?"
- **Word documents**: "Make me a Word document called Plan with ..." A real .docx with headings, bullet points,
  numbered lists, bold words and tables, saved in Documents (or the folder you say) and shown on the screen.
- **Excel spreadsheets**: "Make an Excel sheet of my prices." A real .xlsx, header row in bold, columns sized.
- **PowerPoint decks**: "Make a PowerPoint pitch about Kinetic, 5 slides." A widescreen .pptx with a title
  slide, bullet slides and speaker notes.
- **Read PDFs and Office files**: "Read the TKS brief PDF", "What's in Prices.xlsx?" Works for .pdf, .docx,
  .xlsx, .pptx, .csv, .txt and .md files in the memory folders. A new file never overwrites an old one.

## Already in Alfred
Browser (his own Playwright browser), documents and spreadsheets, PDF export, memory search and files, tool
search, memory, skills, computer use and the Claude app's connectors (MCP bridge).

## Left out on purpose
- Claude's code sandbox: it runs on Anthropic's machines and is billed after the free hours.
- Image and video making: Higgsfield credits are paid, so it still asks before spending.
