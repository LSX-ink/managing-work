# Web Interface Guidelines

Review files for compliance with Web Interface Guidelines.

## How It Works

1. Read the rules in this skill's file `references/rules.md` (the Web Interface Guidelines, saved with the skill)
2. Read the page or files being made or reviewed
3. Check them against every rule
4. Fix what fails (or, when only reviewing, list findings as `file:line` notes)

The rules come from github.com/vercel-labs/web-interface-guidelines (command.md), saved locally so no fetch is needed.
